# 진도표 서식과 예시

주차별 진도표를 만들 때 이 서식을 따른다. 학교·과목마다 열을 더하거나 빼도 되지만, 아래 여섯 열은 진도표가 실제로 작동하는 데 필요한 최소 뼈대다.

## 열 구성

| 열 | 담는 내용 | 비는 경우 |
| --- | --- | --- |
| 주차 | 1, 2, 3 … 학기 주차 번호 | 비우지 않는다 |
| 기간 | 그 주의 월/일 범위 (예: 3.4~3.8) | 학사일정에서 계산 |
| 단원·차시 | 단원명 + 그 주에 나갈 차시(예: 1단원 3~4차시) | 시험·행사 주는 진도 대신 사유 표기 |
| 교과서 쪽 | 그 차시에 해당하는 쪽수 | 자료 없으면 빈칸(지어내지 않음) |
| 성취기준 | 단원에 맞는 코드 | 자료 없으면 빈칸 |
| 평가·비고 | 지필/수행평가, 시험, 행사, 준비물 등 | 없으면 빈칸 |

## 채우는 규칙

- **시험 주**: 단원·차시 칸에 "중간고사(범위: 1~2단원)"처럼 범위를 함께 적는다. 진도 차시는 넣지 않는다.
- **행사·휴업 주**: "체육대회", "재량휴업", "현장체험학습"으로 명시하고 진도를 비운다. 그 주에 수업이 일부만 빠지면 차시를 줄여서 반영한다.
- **시험 전후**: 시험 직전 주에는 "단원 정리·문제 풀이", 직후 주에는 "시험 피드백·오답 정리" 차시를 둔다.
- **수행평가**: 과제를 수행할 수 있을 만큼 단원을 배운 주에 배치하고, 평가·비고 칸에 "수행평가: (항목명)"으로 적는다.

## 예시 (중1 · 주 4차시 · 1학기)

가상의 단원 구성으로 형식만 보여 준다. 실제 단원명·쪽·성취기준은 교사가 준 자료로 바꾼다.

| 주차 | 기간 | 단원·차시 | 교과서 쪽 | 성취기준 | 평가·비고 |
| --- | --- | --- | --- | --- | --- |
| 1 | 3.4~3.8 | 오리엔테이션 + 1단원 1~3차시 | 10~19 | (해당 코드) | 수업 약속·평가 안내 |
| 2 | 3.11~3.15 | 1단원 4~7차시 | 20~31 | (해당 코드) | |
| 3 | 3.18~3.22 | 1단원 8차시 + 2단원 1~3차시 | 32~45 | (해당 코드) | 수행평가① 예고 |
| … | | | | | |
| 8 | 4.22~4.26 | 단원 정리·문제 풀이 | | | 중간고사 대비 |
| 9 | 4.29~5.3 | 중간고사(범위: 1~2단원) | | | 지필평가① |
| 10 | 5.7~5.10 | 시험 피드백·오답 정리 + 3단원 1차시 | 68~73 | (해당 코드) | 어린이날 5.5 휴일 |

## 반별 달력 진도표 (여러 반을 가르칠 때)

마스터 진도표(차시 순번 기준)와 별도로, 반마다 그 차시가 며칠에 걸리는지 보여 준다. `scripts/schedule.py`의 출력을 그대로 옮기면 된다.

| 차시 | 내용(마스터에서) | 1반 | 2반 | 3반 |
| --- | --- | --- | --- | --- |
| 1 | 1단원 도입 | 3.2(월) | 3.4(수) | 3.5(목) |
| 2 | 1단원 개념 | 3.3(화) | 3.4(수) | 3.6(금) |
| … | | | | |

내용 칸은 마스터 진도표에서 한 번만 쓰고, 반별 열에는 날짜만 채운다. 같은 차시라도 반마다 날짜가 다른 것이 정상이다.

## 반별 누적 시수 현황표

특정 날짜 기준으로 각 반이 몇 차시까지 왔는지, 격차가 얼마인지 한눈에 본다.

| 반 | 현재 차시(예: 5.8 기준) | 비고 |
| --- | --- | --- |
| 1반 | 16차시 | 재량휴업으로 −1 |
| 2반 | 18차시 | |
| 3반 | 18차시 | |

격차가 1차시를 넘으면 앞선 반은 예비(버퍼) 차시로 정리·심화하고, 늦은 반이 진도로 따라잡아 시험 전에 같은 차시에 도달하도록 맞춘다.

## 시수 합계 요약(표 아래에 붙인다)

교사가 한눈에 검토하도록 진도표 끝에 배분 합계를 붙인다.

```
실수업 주수: 13주 / 주당 4차시 / 진도용 총 48차시
 1단원 12차시 · 2단원 14차시 · 3단원 12차시 · 4단원 10차시  (합 48)
 지필 2회(중간·기말) · 수행 3항목
```
