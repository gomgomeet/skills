# 예시: 4학년 사회 · 민주주의와 자치

이 폴더는 `assessment-design` 10단계로 실제로 만든 산출물 예시다. 새 수업을 설계할 때 형식과 수준을 참고한다. (내용은 이 수업 전용이므로 그대로 쓰지 말고, 각 수업의 성취기준·기사·활동에 맞게 다시 만든다.)

## 설계 요약

- 대상/교과: 초등 4학년 사회
- 단원: 8. 민주주의와 자치
- 성취기준: **[4사08-01]** 학교 자치 사례를 통하여 민주주의의 의미를 이해하고, 학교생활에서 민주주의를 실천하는 능력을 기른다.
- 자료: 신문기사(신탄진중 학생회·학생참여예산제, 학생 자치 사례)
- 평가목표: 학생은 신문기사를 읽고 참여 사례를 찾아, 그에 대한 자신의 의견을 까닭과 함께 쓸 수 있다.
- 관찰 기준(추상어를 셀 수 있는 기준으로 내림):
  - ㉠ 참여한 사람 (누가 참여했는지)
  - ㉡ 참여한 행동 (한 일이 기사에 실제 나옴)
  - ㉢ 내 의견 (기사 내용에 대한 자기 생각·판단)
  - ㉣ 까닭 (그 의견의 이유: 왜냐하면 ~, ~때문에)
  - 사례 점수 = ㉠㉡ 합(0~2), 의견 점수 = ㉢㉣ 합(0~2), 수준 = 네 표시 개수(4/3/2/1이하 → 매우잘함/잘함/보통/노력요함)

## 파일

- [`rubric.html`](./rubric.html) : 교사용 **평가 기준안**(수행평가 기준안 서식). 인쇄/PDF.
- [`worksheet.html`](./worksheet.html) : 학생용 **온라인 평가지**. 기사 읽기 + 답 쓰기 + 자기 점검 미리보기, 브라우저 자동 임시저장, 인쇄/PDF 제출. (수집은 안 됨: [SKILL.md](../../SKILL.md)의 "온라인 평가지를 만들 때" 참고.)
- [`dashboard.html`](./dashboard.html) : 교사용 **채점·집계 대시보드**. 아티팩트 `db` 저장 + `sample`로 **AI 채점 제안**(학생 답에서 근거 인용) + `downloads` CSV 내보내기. AI는 제안만 하고 최종 체크는 교사가 확정한다.

## 이 예시에서 지킨 원칙

- 성취기준은 라이브러리 원문 그대로 썼고, 기사는 줄이지 않고 전체를 실었다.
- 평가 기준에서 "의견을 잘 씀", "뜻이 통하게" 같은 추상어를 모두 **관찰해서 셀 수 있는 기준**(내 의견 표현 + 까닭)으로 바꿨다.
- AI 채점은 학생 답에 실제로 있는 근거만 인용해 제안하고, 확정은 교사가 한다. 결과물에 없는 것은 추론하지 않는다.
