# 교육과정 라이브러리

교과·학년군별 **성취기준 원문**을 저장하는 곳이다. `assessment-design` 스킬은 2단계(성취기준 분석)에서 반드시 이 폴더를 먼저 읽는다. 성취기준을 기억으로 지어내지 않기 위한 근거 저장소다.

## 파일 규칙

- 파일 이름: `<교과 영문 슬러그>-<학년군>.md`
  - 교과 슬러그: `korean`(국어), `moral`(도덕), `social`(사회), `math`(수학), `science`(과학), `music`(음악), `art`(미술), `english`(영어). 추가 시 `pe`(체육), `practical`(실과) 등.
  - 학년군: `1-2`, `3-4`, `5-6`. (초등 성취기준은 학년 단위가 아니라 학년군 단위다. 예: 4학년 수업이면 `3-4` 파일을 본다.)
- 한 파일 안에 그 교과·학년군의 영역(단원)과 성취기준을 담는다.
- 성취기준은 **코드와 문장을 교육부 고시 원문 그대로** 적는다. 요약하거나 바꾸지 않는다.

## 새 교과·학년군 추가하는 법

1. [`_template.md`](./_template.md)를 복사해 `<교과>-<학년군>.md`로 이름을 바꾼다.
2. 성취기준 원문을 채운다. 원문이 없으면 채우지 않는다. 스킬이 교사에게 원문을 요청한다.
3. 출처(교육과정 고시 문서명, 개정 연도)를 파일 위쪽에 적는다.

## 주의

- 여기 없는 성취기준을 스킬이 만들어 내면 안 된다. 비어 있으면 비어 있는 대로 두고, 교사에게 원문을 받아 채운다.
- 지금 파일들은 별책 PDF에서 자동 추출한 것이다. 문장 내용은 원문과 대조했고, PDF 줄바꿈으로 생긴 단어 내 공백은 정리했다. 특정 성취기준을 정밀 대조하려면 국가교육과정정보센터(ncic.re.kr) 원문과 비교하면 된다.
- 개정 교육과정이 바뀌면 파일을 갱신한다. 옛 코드와 새 코드를 섞지 않는다.
