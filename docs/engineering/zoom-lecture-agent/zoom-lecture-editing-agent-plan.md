# 줌 수업 후 영상 편집 에이전트 설계안

## 목표

줌 수업이 끝나고 녹화 파일이 저장되면, 에이전트가 자동으로 녹화 폴더를 감지하고
분석을 시작한다. 무음, 시작 대기, 불필요한 멈춤, 반복 발화 후보를 찾아 컷 리스트를
제안하고, 사용자가 승인하면 마스터 영상, 자막, 대본, 분할본, 쇼츠 후보까지 이어서
생성한다.

핵심 방향은 완전 자동 삭제가 아니라 `자동 분석 + 사람 승인 + 자동 렌더` 구조다.
강의 영상은 시연, 학생 질문, 화면 공유 맥락이 중요해서 무음만 보고 자르면 위험하다.

## 기본 원칙

1. 원본 영상은 절대 덮어쓰지 않는다.
2. 영상과 음성 원본은 외부 API로 보내지 않고 로컬에서 처리한다.
3. 컷 리스트와 완성 대본은 사용자가 승인한 뒤에만 렌더링한다.
4. 풀영상, 20분 분할본, 쇼츠는 하나의 마스터 영상에서 파생한다.
5. 실패 원인과 해결 방법은 작업별 로그와 `TROUBLESHOOTING.md`에 남긴다.

## 에이전트 구성

### 1. 감지 에이전트

- Windows 줌 녹화 기본 폴더를 감시한다.
- 새 수업 폴더가 생기고 `zoom_0.mp4` 또는 가장 큰 mp4 파일의 쓰기가 끝나면 작업을 만든다.
- 파일 크기가 일정 시간 동안 변하지 않을 때 녹화 완료로 판단한다.
- 같은 폴더를 중복 처리하지 않도록 `job_state.json`에 상태를 저장한다.

### 2. 인제스트 에이전트

- 녹화 폴더에서 본 영상, 오디오, 채팅, 자막 파일을 찾는다.
- 결과를 `manifest.json`으로 정리한다.
- 영상이 여러 개인 경우 가장 큰 파일을 본 영상으로 고르되, 사용자에게 확인 메시지를 남긴다.

### 3. 분석 에이전트

- 무음 구간을 찾는다.
- 화면 정지 구간을 함께 분석해, 무음이지만 화면 시연이 진행 중인 구간을 보호한다.
- 시작 대기, 긴 침묵, 수업 종료 후 남은 부분, 반복 발화 후보를 분류한다.

### 4. 편집 계획 에이전트

- `edl.md`와 `edl.json`을 만든다.
- 컷 후보를 `자동 컷`과 `확인 필요`로 나눈다.
- 사용자가 "3번은 살려줘", "7번도 잘라줘", "무음 2초 이상만"처럼 말하면 컷 리스트를 다시 만든다.

### 5. 전사/자막 에이전트

- 로컬 faster-whisper로 한국어 전사를 만든다.
- 컷 경계가 말끝을 먹지 않도록 단어 타임스탬프 기준으로 보정한다.
- 자주 틀리는 교육 용어와 고유명사를 교정 사전으로 관리한다.
- `master.srt`와 `final_script.md`를 만든다.

### 6. 렌더 에이전트

- 승인된 `edl.json`으로 마스터 영상을 만든다.
- 마스터 길이와 예상 길이를 비교해 1초 이상 차이 나면 경고한다.
- 마스터에서 풀영상, 20분 분할본, 쇼츠 후보를 파생한다.

### 7. 검수 에이전트

- 시작/끝, 컷 경계, 전환 지점의 프레임을 이미지로 뽑아 검수한다.
- 화면 공유 중 개인정보, 알림 팝업, 참가자 명단 노출 여부는 초기 버전에서는 사용자 확인 항목으로 둔다.
- 추후 자동 블러/마스킹으로 확장한다.

## 권장 작업 흐름

## MVP 범위

첫 버전은 아래까지만 만든다.

- 줌 녹화 폴더 수동 지정 또는 자동 감지
- 인제스트
- 무음 + 화면 정지 분석
- 컷 리스트 제안
- 사용자 승인 반영
- 마스터 영상 렌더
- 기본 SRT 자막 생성
- 작업 로그와 산출물 폴더 정리

MVP에서는 쇼츠 자동 추출, 개인정보 자동 검출, 유튜브 업로드까지는 넣지 않는다.
편집 품질과 안전한 승인 흐름이 먼저다.

## 2단계 확장

- 20분 단위 분할본 자동 생성
- 수업 제목, 날짜, 차시 기준 파일명 자동 정리
- 자주 쓰는 인트로/아웃트로 삽입
- 자막 용어 사전 관리
- 최종 검수 리포트 생성
- 썸네일 후보 프레임 추출

## 3단계 확장

- 쇼츠 후보 자동 추출
- 챕터 자동 생성
- 화면 노출 위험 구간 자동 탐지
- 유튜브 설명문, 태그, 고정 댓글 초안 생성
- 처리 완료 알림

## 내 제안

이 에이전트는 처음부터 완전 자동 편집기로 만들기보다, "편집 조교"처럼 만드는 것이 좋다.
수업 영상은 틀린 컷 하나가 강의 맥락을 망칠 수 있으므로 자동화는 분석과 반복 작업에 집중하고,
삭제 결정은 사람에게 짧고 명확하게 물어보는 구조가 안전하다.

또 하나의 중요한 선택은 "수업 직후 바로 렌더"가 아니라 "수업 직후 바로 분석"이다.
분석 결과와 컷 리스트가 먼저 준비되어 있으면 사용자는 나중에 1~2분만 보고 승인할 수 있다.
승인 뒤에는 에이전트가 오래 걸리는 렌더를 알아서 진행한다.

## 구현 계획

## 현재 구현 상태

이번 MVP 구현으로 `skills/misc/zoom-recording-autopilot/scripts/agent.py`가 추가되었다.

- `doctor`: `ffmpeg`, `ffprobe`, Python, `faster-whisper`, 기존 편집 스크립트 확인
- `prepare`: 녹화 폴더를 인제스트하고 무음/화면정지 분석 후 `edl.md` 생성
- `replan`: 컷 살리기, 확인 필요 컷 승인, 무음 기준 조정
- `transcribe`: 컷 승인 후 로컬 전사, 컷 보정, SRT와 검수 대본 생성
- `render`: 컷 승인 후 마스터 렌더, 대본이 있으면 대본 승인도 요구
- `watch`: 줌 녹화 폴더 감시, 파일 크기가 안정되면 자동으로 `prepare` 실행

합성 줌 녹화로 `prepare → replan → render(draft)`까지 검증했다.
검증 중 발견한 한글 Windows 콘솔 인코딩 문제는 하위 Python 실행을 UTF-8로 강제해
해결했고, `docs/engineering/zoom-lecture-agent/TROUBLESHOOTING.md`에 기록했다.

### Phase 1: 로컬 파이프라인 고정

- 기존 편집 스크립트의 실행 경로와 의존성을 확인한다.
- `ffmpeg`, `ffprobe`, `faster-whisper` 설치 여부를 점검한다.
- 샘플 줌 녹화 폴더 하나로 수동 실행 흐름을 검증한다.
- 산출물 폴더와 로그 형식을 확정한다.

### Phase 2: 작업 감지와 큐

- 줌 녹화 폴더 감시기를 만든다.
- 녹화 완료 판정 로직을 만든다.
- 작업 상태 저장소를 만든다.
- 이미 처리한 폴더를 건너뛰게 한다.

### Phase 3: 승인 인터페이스

- `edl.md`를 읽기 쉬운 승인표로 만든다.
- 사용자가 컷 번호를 살리거나 추가할 수 있게 한다.
- 승인 후에만 렌더가 진행되도록 잠금 상태를 둔다.

### Phase 4: 자동 렌더와 산출물

- 마스터 렌더를 자동 실행한다.
- SRT 자막과 완성 대본을 만든다.
- 20분 분할본과 풀영상 export를 추가한다.

### Phase 5: 품질 검수

- 컷 경계 프레임을 추출한다.
- 검수 리포트를 만든다.
- 개인정보 노출과 화면 알림은 초기에는 체크리스트로 두고, 이후 자동 탐지로 확장한다.

## 다음에 결정할 것

1. 줌 녹화 폴더를 자동 감시할지, 처음에는 수동으로 폴더를 넣을지
2. 결과물을 유튜브용으로 고정할지, LMS/구글드라이브 업로드용도 함께 고려할지
3. 인트로/아웃트로, 워터마크, 자막 스타일을 기본으로 넣을지
4. 쇼츠가 실제로 필요한지, 필요하다면 어떤 장면을 우선 추출할지
5. 처리 완료 알림을 Codex 안에서 받을지, 이메일/캘린더/메신저로 받을지
