# 노션톡 라이브 챌린지 1기 웨비나 PPT

곰곰이쌤의 「노션 자동화의 모든 것: 나만의 데이터베이스 자동화 완성하기」 웨비나 발표 자료입니다. 블랙 앤 화이트 디자인이며, 슬라이드는 49장입니다.

- 원본 노션 페이지: [노션 자동화 라이브 챌린지](https://judicious-ursinia-2c0.notion.site/412c5f01a4a4804cabd3c294d5d93fc9)
- 완성본: [`notiontalk-live-challenge-1-webinar.pptx`](./notiontalk-live-challenge-1-webinar.pptx)

## 슬라이드 구성 (90분 기준)

| 구간 | 슬라이드 | 내용 |
|---|---|---|
| 오프닝 | 1~7 | 표지, 강사 소개, 자료실, 목표, 타임테이블, 세팅(QR), 자동화 3가지 스위치 |

| PART 3 버튼 수식·변수 | 23~31 | 수식 속성과 버튼 수식, 숫자·날짜 계산, 변수 정의, 실습실, 수식 모음집 |

## 발표 전에 채울 곳

- 표지의 일시
- 마지막 슬라이드의 1주차 인증 마감일
- 실제 웨비나 시간이 90분이 아니라면 5번 슬라이드 타임테이블

## 집 컴퓨터에서 이어서 수정하기

PPT를 직접 고쳐도 되지만, 디자인을 한꺼번에 바꾸거나 슬라이드를 추가할 때는 스크립트로 다시 만드는 편이 빠릅니다.

```bash
cd webinars/notiontalk-live-challenge-1
```

```bash
npm install
```

```bash
npm run build
```

- `build.js`: 슬라이드 내용과 디자인을 정의합니다. 색은 파일 위쪽 `COL` 팔레트에서 한 번에 바꿀 수 있습니다.
- `assets/`: 노션 페이지 캡처(흑백), 일러스트, 곰돌이 캐릭터 이미지입니다. 파일 이름의 `p03_s04`는 3번 페이지(버튼 사용의 모든 것)의 4번째 소제목 구간이라는 뜻이고, `_a`, `_b`는 긴 캡처를 둘로 나눈 조각입니다.
- `capture-tools/`: 노션 페이지를 다시 캡처할 때 쓰는 Playwright 스크립트입니다. 노션 내용이 바뀌면 `capture-sections.js`로 소제목 단위 캡처를 새로 만든 뒤 `assets/`를 교체하세요.

## 유의사항

- 캡처와 인증 예시에는 가상 자료만 사용했습니다. 실제 학생 정보는 넣지 않습니다.
- 노션 페이지 안의 그로블 링크 카드에는 "2회차"로 적혀 있습니다. 슬라이드는 "1기"로 표기했습니다.
